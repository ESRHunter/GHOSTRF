# Принципиальная схема Carrier Board с модулем CC1101 (2x4) и разъемом батареи 2.54 мм

Схема платы-переходника для подключения готовых модулей: **ESP32-C3 SuperMini**, радиомодуля **CC1101 (2x4)**, дисплея **OLED SSD1306**, кнопок и разъема аккумулятора с шагом **2.54 мм**.

---

## 📡 Распиновка разъема CC1101 2x4 (8-Pin, шаг 2.54 мм)

```
          [ Модуль CC1101 2x4 (Вид сверху на плату) ]
                     ┌───[ SMA ]───┐
                     │             │
                     │   CC1101    │
                     │             │
                     │  1  3  5  7 │  <-- Ряд 1: [VCC]  [MOSI] [MISO] [GDO0]
                     │  2  4  6  8 │  <-- Ряд 2: [GND]  [SCLK] [GDO2] [CSN]
                     └─────────────┘
```

| Пин 2x4 | Шелкография | Пин ESP32-C3 SuperMini | Назначение |
|---|---|---|---|
| **Pin 1** | **VCC** | **3V3** | Питание 3.3 В (строго 3.3 В!) |
| **Pin 2** | **GND** | **GND** | Общий провод (Земля) |
| **Pin 3** | **MOSI / SI** | **GPIO 6** | Вход данных в радиомодуль |
| **Pin 4** | **SCLK / SCK** | **GPIO 4** | Тактирование шины SPI |
| **Pin 5** | **MISO / SO** | **GPIO 5** | Выход данных от радиомодуля к ESP32 |
| **Pin 6** | **GDO2** | *NC* (не подключен) | Резерв (в прошивке не используется) |
| **Pin 7** | **GDO0** | **GPIO 3** | Импульсы радиосигнала RX/TX |
| **Pin 8** | **CSN / CS** | **GPIO 7** | Выбор чипа SPI (Chip Select) |

## ⚡ Разъем аккумулятора 2.54 мм (J1) и выключатель питания

```
 [ Аккумулятор 3.7 В ]
  (Разъем J1: шаг 2.54 мм)
   Pin 1 (BAT+) ─────────> [ Выключатель SW4 (SS12D00) ]
   Pin 2 (BAT-) ──┬           Pin 1: NC
                  │           Pin 2: Вход от батареи (BAT+)
                  │           Pin 3: Выход (VBAT_SW) ──┬──> Пин "5V" ESP32-C3 SuperMini
                  │                                    │
                  │                                    └──> [ R1: 100k ] ──┬──> GPIO 10 (АЦП)
                  │                                                        │
                  │                                                    [ R2: 100k ]
                  │                                                        │
                  └────────────────────────────────────────────────────────┴──> Общий GND
```

* **Разъем J1:** 2 контакта с шагом **2.54 мм** (стандартная гребенка PLS-2, разъем JST-XH 2.54 мм, DuPont или прямая пайка проводов в отверстия).
* **Принцип работы:** 
  При включении SW4 напряжение аккумулятора поступает на вход **5V** ESP32-C3 SuperMini. Встроенный стабилизатор LDO преобразует его в **3.3 В**, от которого запитываются SuperMini, CC1101 и OLED.

## 🗺 Полная таблица соединений

| ESP32-C3 SuperMini | Назначение в коде | Подключаемый компонент | Пин компонента |
|---|---|---|---|
| **3V3** | Питание 3.3 В | CC1101 (2x4) + OLED 0.96" | Pin 1 (VCC) CC1101 и Pin 2 (VCC) OLED |
| **GND** | Общая земля | CC1101 + OLED + Кнопки + АКБ | Pin 2 CC1101, Pin 1 OLED, кнопки, Pin 2 (BAT-) J1 |
| **5V / VIN** | Вход питания АКБ | Выключатель SW4 | Pin 3 (VBAT_SW) выключателя |
| **GPIO 0** | Кнопка «ВВЕРХ» | Кнопка SW1 | Контакт 1 (второй контакт на GND) |
| **GPIO 1** | Кнопка «ОК» | Кнопка SW2 | Контакт 1 (второй контакт на GND) |
| **GPIO 2** | Кнопка «ВНИЗ» | Кнопка SW3 | Контакт 1 (второй контакт на GND) |
| **GPIO 3** | Импульсы радио RX/TX | Модуль CC1101 (2x4) | **Pin 7 (GDO0)** |
| **GPIO 4** | SPI такты (SCK) | Модуль CC1101 (2x4) | **Pin 4 (SCLK)** |
| **GPIO 5** | SPI MISO | Модуль CC1101 (2x4) | **Pin 5 (MISO / SO)** |
| **GPIO 6** | SPI MOSI | Модуль CC1101 (2x4) | **Pin 3 (MOSI / SI)** |
| **GPIO 7** | SPI CSN | Модуль CC1101 (2x4) | **Pin 8 (CSN)** |
| **GPIO 8** | I2C данные SDA | Экран OLED 0.96" | **Pin 4 (SDA)** |
| **GPIO 9** | I2C такты SCL | Экран OLED 0.96" | **Pin 3 (SCL)** |
| **GPIO 10** | Замер заряда АКБ | Делитель R1 / R2 (100k/100k) | Средняя точка делителя с шины питания |
| **GPIO 20** | Зуммер (звук) | Пьезозуммер BZ1 | Пин (+) зуммера (минус на GND) |
