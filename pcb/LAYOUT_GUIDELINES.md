# Руководство по компоновке и трассировке Carrier Board

Материнская плата под готовые модули разводится на **простой 2-слойной плате**. Здесь нет мелких ВЧ-цепей (все они уже спрятаны внутри экранированного модуля CC1101), поэтому плата не требует строгих расчетов волнового сопротивления и разводится легко и быстро.

---

## 📐 Рекомендуемые размеры и форма

* **Габариты платы:** **68 × 34 мм** (прямоугольник со скругленными углами радиусом 2–3 мм).
* **Слои:** 2 слоя (Top Layer и Bottom Layer).
* **Толщина платы:** 1.6 мм стандартный FR-4.
* **Ширина проводников:**
  * Сигнальные линии (SPI, I2C, кнопки): **0.25 – 0.35 мм**.
  * Линии питания (3V3, 5V, VBAT): **0.6 – 0.8 мм**.
  * Земля (GND): **Сплошной полигон меди (Copper Pour)** на обоих слоях.

## 🎛 Эргономичное расположение модулей

```
                 [ ВЕРХНИЙ ТОРЕЦ ]
             ┌───────[ SMA ]───────┐
             │    Модуль CC1101    │  <-- Антенный разъем SMA торчит вверх
             │   (разъем 1x8/2x4)  │
             ├─────────────────────┤
             │                     │
             │   Дисплей OLED      │  <-- Экран 0.96" I2C
             │     SSD1306         │      (разъем 1x4 мама сверху)
             │                     │
             ├─────────────────────┤
             │   (▲) Кнопка ВВЕРХ  │  <-- SW1 (GPIO 0)
             │   (●) Кнопка ОК     │  <-- SW2 (GPIO 1)
             │   (▼) Кнопка ВНИЗ   │  <-- SW3 (GPIO 2)
       [SW4] ├─────────────────────┤
      (Выкл) │      ESP32-C3       │  <-- Разъем USB Type-C направлен
       сбоку │     SuperMini       │      строго в нижний торец для зарядки!
             └──────────┬──────────┘
                 [ НИЖНИЙ ТОРЕЦ ]
```

## 💡 Практические советы по сборке

1. **Универсальное посадочное место для CC1101:**
   Нарисуйте на плате сразу две параллельные гребенки: **1x8** и **2x4**. Соедините соответствующие пины между собой на плате. Тогда любой купленный модуль CC1101 (будь то узкий 1x8 или квадратный 2x4) подойдет без переделок!
2. **Съемная установка на панельки (PBS-гнезда):**
   Рекомендуется впаивать в материнскую плату гнезда PBS (шаг 2.54 мм), а модули (ESP32-C3 SuperMini, OLED, CC1101) вставлять в них на штырьках. Это позволит легко заменить модуль в случае поломки.
3. **Размещение аккумулятора:**
   Плоский Li-Po аккумулятор 3.7 В (толщиной 4–6 мм) крепится на тыльную сторону (Bottom) материнской платы на полоску двухстороннего вспененного скотча 3M. Разъем JST-PH 2.0 мм припаивается рядом.
4. **Отверстия для крепления в корпус:**
   Разместите 4 монтажных отверстия диаметром **2.2 мм** (под винтики М2) по углам платы для удобной установки в 3D-печатный корпус.
