# RF-Hub 433 Studio 📡

**Кроссплатформенное графическое приложение на C++ / Qt 6 для чтения, анализа, генерации, передачи радиосигналов и полного управления портативным мультитулом на ESP32-C3 + CC1101.**

---

## 🌟 Основные возможности

### 1. 📂 Полный менеджер сохранённых сигналов
* **Чтение всей информации из памяти Flash (NVS):**
  * Имя сигнала, тип (Фиксированный, RAW-импульсы, KeeLoq брелок, EV1527 Smart).
  * Несущая частота CC1101 (300.00 – 928.00 МГц с точностью до кГц).
  * Протокол кодирования (EV1527, PT2262, Came 12-bit, Nice 12-bit, KeeLoq, RAW).
  * Код в форматах **HEX**, **DEC** и **двоичной битовой маске (BIN)** с разделителями.
  * Битность пакета, базовый период импульса (TE в микросекундах $\mu s$), количество повторов передачи.
  * Для брелоков **KeeLoq (HCS200 / HCS300 / HCS301)**: 28-битный серийный номер, код нажатой кнопки, зашифрованный динамический счетчик.
* **Интерактивный цифровой микро-осциллограф (Waveform Viewer):**
  * Отображение логических уровней (HIGH / LOW) с временной шкалой.
  * Плавный зум колёсиком мыши и панорамирование перетаскиванием.
  * Подсветка любого импульса при наведении курсора с отображением точной длительности в $\mu s$ и таймингов начала/конца.
  * Инвертирование полярности формы волны.
  * Автоматический синтез формы сигнала даже для фиксированных кодов (Came, Nice, EV1527, PT2262)!
* **Управление и резервное копирование:**
  * Добавление, редактирование и удаление сигналов из Flash-памяти устройства.
  * **Экспорт и импорт в формат Sub-GHz (`.sub`):** полная совместимость с ключами и RAW-дампами радиосистем!
  * **Полный бэкап и восстановление (JSON):** сохранение всей базы сигналов на ПК в один клик.

### 2. 📡 Передатчик и генератор собственных сигналов
* **Фиксированный код:**
  * Выбор протокола (EV1527, PT2262, Came, Nice, RC-Switch).
  * Синхронный ввод в HEX или DEC.
  * Настройка битности, базовой длительности импульса ($50 - 5000\ \mu s$), количества повторов и мощности передатчика CC1101 (от $-30\ \text{dBm}$ до $+10\ \text{dBm}$).
  * Живая визуализация синтезируемого сигнала перед передачей.
  * Кнопка мгновенной отправки в эфир или сохранения в память устройства.
* **RAW-импульсы:**
  * Редактор произвольных микросекундных последовательностей импульсов.
  * Быстрые пресеты: шлагбаумы Came 12b, ворота Nice Flo, беспроводные радиозвонки EV1527.
  * Прямой парсинг формата `RAW_Data`.
* **Генератор несущей частоты / Тестовый маяк (Carrier Beacon):**
  * Режимы: немодулированная несущая (CW), тональный сигнал 1 кГц (Square Wave), шумовой сигнал подавления (Jamming Noise).
  * Настройка мощности и частоты с защитой от случайного включения.

### 3. 🎮 Дистанционное управление устройством и Live-Сниффер
* **Виртуальный пульт управления:**
  * Дистанционные кнопки: ВВЕРХ, ВНИЗ, ОК (короткое нажатие), УДЕРЖАНИЕ ОК (>0.75 с для возврата в главное меню).
  * Полное управление OLED-экраном и навигацией меню устройства прямо с ПК.
* **Live Сниффер радиоэфира:**
  * Запуск RX-сниффера фиксированных кодов или RAW-сниффера прямо из программы.
  * Таблица пойманных пакетов в реальном времени: точное время, частота, протокол, HEX-код, длина, тайминги, уровень сигнала RSSI ($\text{dBm}$).
  * Быстрые действия по любому пойманному пакету: мгновенный повтор в эфир (**Replay TX**), сохранение во Flash-память, экспорт.
* **Аппаратные настройки CC1101:**
  * Выбор рабочей частоты, мощности PA и порога аппаратного шумоподавителя (Squelch: $-85$, $-78$, $-72$, $-65\ \text{dBm}$).
  * Перезагрузка микроконтроллера ESP32-C3.

### 4. 💻 Интерактивная Serial-консоль
* Цветовая дифференциация отправленных (TX) и принятых (RX) JSON/ASCII сообщений с точностью до миллисекунд.
* Прямой ввод команд с автоскроллом и очисткой.

## 🛠 Сборка и запуск

Приложение написано на стандартном **C++17** и **Qt 6** (с обратной совместимостью с Qt 5) с использованием системы сборки **CMake**.

### Linux (Arch Linux / Manjaro)
```bash
sudo pacman -S cmake ninja gcc qt6-base qt6-serialport
cd /home/esrhunter/Документы/задачи
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
./build/RFHubStudio
```

### Linux (Ubuntu / Debian / Linux Mint)
```bash
sudo apt update
sudo apt install build-essential cmake ninja-build qt6-base-dev libqt6serialport6-dev
cd /path/to/project
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
./build/RFHubStudio
```

### Windows (MSVC или MinGW)
1. Установите **Qt 6** (компоненты: `Qt Core`, `Qt Gui`, `Qt Widgets`, `Qt SerialPort`) и **CMake**.
2. В командной строке (x64 Native Tools Command Prompt или PowerShell):
```cmd
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
.\build\Release\RFHubStudio.exe
```

### macOS (Apple Silicon / Intel)
```bash
brew install cmake qt
cmake -B build -S . -DCMAKE_PREFIX_PATH=$(brew --prefix qt)
cmake --build build
open ./build/RFHubStudio.app
```

## 🔌 Протокол обмена Serial (USB CDC, 115200 бод)

Приложение обменивается с прошивкой ESP32-C3 компактными строками команд и JSON-ответами через `Serial`:

| Команда | Описание | Ответ устройства |
|---|---|---|
| `PING` | Запрос статуса и телеметрии | `{"cmd":"PONG","device":"GHOSTRF","ver":"1.2.0","chip":"ESP32-C3","cc1101":true,"free_heap":...,"signals_count":...}` |
| `GET_SIGNALS` | Запрос всех сохраненных сигналов | `{"cmd":"SIGNALS_BEGIN","count":N}` $\to$ строки `{"cmd":"SIGNAL",...}` $\to$ `{"cmd":"SIGNALS_END"}` |
| `TX_SAVED <idx>` | Отправка сохраненного сигнала №idx | `{"cmd":"TX_DONE","status":"OK","index":idx}` |
| `TX_FIXED <f> <code> <bits> <te> <proto> <pa> <rep>` | Передача произвольного фиксированного кода | `{"cmd":"TX_DONE","status":"OK"}` |
| `TX_RAW <f> <pa> <rep> <count> <p0,p1...>` | Передача произвольного пакета RAW импульсов | `{"cmd":"TX_DONE","status":"OK","count":...}` |
| `SAVE_FIXED <name> <f> <code> <bits> <te> <proto> <rep>` | Запись фиксированного сигнала в Flash (NVS) | `{"cmd":"SAVE_DONE","status":"OK","count":N}` |
| `SAVE_RAW <name> <f> <rep> <proto> <isK> <ser> <btn> <enc> <cnt> <pulses>` | Запись RAW сигнала в Flash (NVS) | `{"cmd":"SAVE_DONE","status":"OK","count":N}` |
| `DELETE_SIGNAL <idx>` | Удаление сигнала со сдвигом списка | `{"cmd":"DELETE_DONE","status":"OK","count":N}` |
| `CLEAR_SIGNALS` | Полная очистка списка сигналов | `{"cmd":"CLEAR_DONE","status":"OK"}` |
| `SET_CONFIG <freqIdx> <paIdx> <sqIdx>` | Запись аппаратных настроек в NVS | `{"cmd":"CONFIG_SAVED","status":"OK"}` |
| `REMOTE_BTN <UP/DOWN/OK/OK_HOLD>` | Симуляция нажатия аппаратных кнопок | `{"cmd":"REMOTE_BTN_ACK","btn":"..."}` |
| `START_SNIFFER <FIXED/RAW>` | Переключение в режим сниффера эфира | `{"cmd":"SNIFFER_STARTED","mode":"..."}` |
| `STOP_SNIFFER` | Остановка сниффера эфира | `{"cmd":"SNIFFER_STOPPED"}` |
| `SET_CARRIER <mode> <freq> <pa> <1/0>` | Включение/выключение несущей | `{"cmd":"CARRIER_DONE","status":"ON/OFF"}` |
| `REBOOT` | Программная перезагрузка микроконтроллера | `{"cmd":"REBOOTING"}` |
