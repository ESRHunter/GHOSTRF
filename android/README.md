# МОБИЛЬНОЕ ПРИЛОЖЕНИЕ GHOSTRF STUDIO (ANDROID / BLUETOOTH)

Данная папка содержит мобильное приложение для управления устройством **ESP32-C3 + CC1101** по **Bluetooth Low Energy (BLE 5.0)** в строгом черно-белом квадратном стиле.

---

## Вариант 1: Мгновенный запуск на Android через Google Chrome (Web Bluetooth PWA)
Папка: `android/web_ble/`

**Установка компиляторов и Android Studio НЕ требуется!**
1. Запустите локальный веб-сервер на ПК в папке `web_ble`:
   ```bash
   cd /home/esrhunter/Документы/cc1101/android/web_ble
   python3 -m http.server 8080
   ```
2. Откройте в браузере **Google Chrome** на смартфоне Android адрес: `http://<IP_ВАШЕГО_ПК>:8080` (или откройте `index.html`).
3. Нажмите кнопку **`[ ПОДКЛЮЧИТЬ ]`**, выберите в списке устройств **`GHOSTRF`**.
4. Экран OLED 128x64 начнет транслироваться прямо на телефон с полным управлением по кнопкам пульта и быстрым выбором режима!
5. В меню Chrome выберите **"Добавить на главный экран"** — приложение установится как полноценное мобильное приложение (PWA).

## Вариант 2: Нативное Android Studio приложение (Kotlin / Gradle)
Папка: `android/RFHubMobile/`

Полноценный нативный проект для Android Studio:
* **Язык**: Kotlin
* **BLE стек**: BluetoothGatt, Nordic UART Service (NUS `6E400001-...`)
* **Отрисовка**: `OledCanvasView` — аппаратный кастомный View для попиксельной отрисовки SSD1306 128x64
* **Стиль**: Строгий квадратный монохром (Black & White, без смайликов)
* **Минимальная версия Android**: Android 7.0 (API 24+)

### Сборка и установка:
1. Откройте Android Studio.
2. Выберите **File -> Open...** и укажите папку `/home/esrhunter/Документы/cc1101/android/RFHubMobile`.
3. Подключите телефон по USB с включенной отладкой (USB Debugging).
4. Нажмите **Run 'app' (Shift+F10)**.

## Поддерживаемые функции по Bluetooth:
1. **Прямой стриминг экрана**: живая трансляция OLED SSD1306 128x64 на телефон.
2. **Аппаратный пульт**: кнопки `[ ▲ ВВЕРХ ]`, `[ ● ОК ]`, `[ ▼ ВНИЗ ]`, `[ ⮌ ВОЗВРАТ В МЕНЮ ]`.
3. **Быстрый выбор режима**:
   * `[ 1. МЕНЮ ]`
   * `[ 2. ПРИЕМНИК RX ]`
   * `[ 3. RAW СНИФФЕР ]`
   * `[ 4. СПЕКТРОАНАЛИЗАТОР ]`
   * `[ 5. ЧАСТОТОМЕР ]`
   * `[ 6. ПУЛЬТ TX ]`
   * `[ 7. ГЕНЕРАТОР / ГЛУШИТЕЛЬ ]`
   * `[ 8. НАСТРОЙКИ ]`
   *(нажатие кнопки моментально переключает страницу экрана и радиорежим на самом устройстве!)*
4. **Настройки радиомодуля прямо в сниффере**: выбор частоты (433.92, 315, 868 МГц), мощности PA (+10, 0, -10, -30 dBm) и чувствительности Squelch.
5. **Лог сниффера**: отображение пойманных кодов EV1527, Came, Nice, KeeLoq, RAW импульсов и уровня RSSI.
