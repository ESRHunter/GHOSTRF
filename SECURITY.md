# Security Policy

## Responsible Disclosure

**GHOSTRF** is an educational and security research multi-tool intended for authorized wireless protocol analysis, penetration testing, and IoT development.

If you discover a security vulnerability within GHOSTRF firmware, cryptographic implementations (e.g., KeeLoq decryption routines), or web services, please follow responsible disclosure guidelines:

1. **Do NOT open a public GitHub issue** for undisclosed vulnerabilities.
2. Report the vulnerability privately via GitHub Security Advisories or contact the maintainer directly.
3. Include reproducible steps, affected firmware version, and packet captures if applicable.
